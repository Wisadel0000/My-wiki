# WikiEncoder 语法规范 v1

一页一个文件：`pages/<slug>.wiki`，UTF-8（无 BOM）、LF 换行。
文件里只存**事实**（正文、键值、编辑记录表格），目录 / 总次数 / 反链等一律派生。

## 1. 完整示例

```
---
format: 1
title: 傅里叶变换
type: 概念
aliases: FT, Fourier transform
tags: 数学, 变换, 信号处理
created: 2024-05-01
---

@ 序言
傅里叶变换是把函数从时域映射到频域的[[积分变换]]，也是[[傅里叶级数]]在非周期信号上的推广。

@ 标识信息框
领域: 数学 / 分析 / 调和分析
父级: [[积分变换]]
属性: 线性、可逆
相关概念: [[傅里叶级数]]、[[卷积定理]]
应用: 信号处理、量子力学、图像压缩

@ 详细内容
## 历史
傅里叶在 1807 年提出。

## 定义
对 $f\in L^1(\mathbb{R})$：

$$F(\omega)=\int_{-\infty}^{+\infty} f(t)e^{-i\omega t}dt$$

## 性质
- 线性
- 卷积定理：见 [[卷积定理]]

@ 参见
- [[拉普拉斯变换]] —— 更一般的形式

@ 知识来源
书: 《信号与系统》Oppenheim 等
网址: https://en.wikipedia.org/wiki/Fourier_transform

@ 编辑记录
| # | 日期 | 作者 | 说明 |
|---|------|------|------|
| 1 | 2024-05-01 | 我 | 创建条目 |
```

## 2. 语法元素只有 4 种

| 元素 | 写法 | 说明 |
|---|---|---|
| 元数据 | `---` 包住的 `键: 值` | 只支持扁平键值，不嵌套 |
| 板块 | 行首 `@ 板块名` | **没有闭合标记**，下一个 `@` 或文件结束即结束 |
| 围栏 | `::: md` / `::: text` … `:::` | 局部切换渲染模式，永不嵌套超过一层 |
| 链接 | `[[目标]]` | 可以出现在页面的任何位置，见 §3.4 |

### 2.1 元数据（front matter）

必须是文件的第一个块。已知键：

| 键 | 必填 | 说明 |
|---|---|---|
| `format` | 建议 | 语法版本，当前 `1` |
| `title` | 是 | 中文题名 |
| `type` | 否 | `概念 / 定理 / 方法 / 人物 / 术语 / 事件 / 工具…` |
| `aliases` | 否 | 词条别名，逗号分隔，供其他页面`[[别名]]` 反查 |
| `tags` | 否 | 逗号分隔；渲染成信息框里的标签行 |
| `created` | 否 | 创建日期 |

未知键原样保留。**slug 就是文件名**，不要在元数据里重复写。

### 2.2 板块

- 必须从第 0 列开始写 `@`；`@` 后面至少一个非空白字符。
- 板块名称可用某些别名：`序言/定义/引言`、`正文/详细内容/详细介绍`、`参见/另见/相关条目`、`来源/参考资料`、`编辑记录/修改记录`。
- 可强制默认语法模式：`@ 序言 {md}`、`@ 附录 {text}`。
- 未知板块名按**自定义板块**保留并渲染，不会报错。
- 同一板块出现多次 → 警告，以第一个为准。

| 板块 | 规范名 | 内容写法 | 渲染 |
|---|---|---|---|
| 序言 | 序言 | 散文 | 页头导语 |
| 标识信息框 | 标识信息框 | `键: 值`（全角 `：` 也认） | `<dl>` 键值表 |
| 目录 | 目录 | 留空（占位） | 由正文标题自动生成 |
| 详细内容 | 详细内容 | markdown | 正文 |
| 参见 | 参见 | `- [[目标]] —— 注解` | 列表 + 灰色注解 |
| 知识来源 | 知识来源 | `书: …` / `网址: …` | 列表 + 来源类型徽标 |
| 编辑记录 | 编辑记录 | markdown 表格 | 页尾表格 |

信息框的续行：下一行以空格缩进即视为上一条值的续行。

### 2.3 围栏

默认渲染模式按板块决定（序言 / 详细内容 / 自定义板块是 `md`，其余是 `text`）。
需要局部切换时：

```
::: text
这里的 # 和 * 都是普通字符
:::

::: md
**这里** 才按 markdown 渲染
:::
```

规则：
- 开启围栏**必须带模式词**（`md` 或 `text`）；裸 `:::` 一律是闭合。
- 围栏内一切字面：`@` 行、`[[` 都不解析。
- 未闭合 → `E001` 报错并给出行号。
- 嵌套一层用更长的围栏（`::::` … `::::`）。

### 2.4 链接

```
[[积分变换]]               # 显示名自动取目标标题
[[积分变换|更一般的形式]]    # 显式显示名
[[积分变换#定义]]           # 跨页锚点
[[积分变换#定义|定义一节]]   # 两者兼有
```

解析顺序：**slug → 别名 → 标题 → 归一化**（空格/下划线/连字符/大小写不敏感）。
未命中 → 渲染成红链 `class="wikilink broken"`，校验时报警告 `E401`。

## 3. 派生数据（永不落盘）

| 数据 | 来源 |
|---|---|
| 目录 | 详细内容 / 自定义板块里的 `##`~`######` 标题 |
| 总修改次数 | 编辑记录表格的行数 |
| 更新时间 | 最后一条编辑记录的日期 |
| 反向链接 | 全库扫描 `[[...]]` |
| 标签索引 | front matter 的 `tags` |

## 4. HTML 契约

`render_page(page).parts` 给出九段彼此独立的字符串：
`meta_html`、`lead_html`、`infobox_html`、`toc_html`、`body_html`、
`seealso_html`、`sources_html`、`log_html`、`backlinks_html`。

稳定类名（视为公开 API，不随意改名）：

- 页面：`.wiki-page`、`.wiki-header`、`.wiki-title`、`.wiki-meta`、`.wiki-lead`
- 信息框：`.wiki-infobox`、`.wiki-infobox-row`、`.tag`
- 目录：`.wiki-toc`、`.wiki-toc-list`、`.wiki-toc-item`
- 正文：`.wiki-body`、`.wiki-heading`（带 `id` 锚点）、`.wiki-extra`、`.wiki-section-title`
- 链接：`.wikilink`、`.wikilink.broken`
- 参见 / 来源：`.wiki-seealso`、`.wiki-note`、`.wiki-sources`、`.wiki-source-kind`
- 日志：`.wiki-log`、`.wiki-log-summary`、`.wiki-log-table`
- 公式：`.math.inline`、`.math.block`（TeX 在 textContent 里，交给前端 MathJax/KaTeX）

## 5. 错误码

| 码 | 级别 | 含义 |
|---|---|---|
| `E001` | error | 围栏没有闭合 |
| `E002` | error | front matter 没有闭合 |
| `E101` | warn | front matter 行缺少冒号 |
| `E102` | error | 缺少 `title` |
| `E103` | warn | 元数据里的 slug 与文件名不一致 |
| `E104` | error | 文件不是合法 UTF-8 |
| `E201` | warn | 信息框行缺少「键: 值」 |
| `E301` | warn | 编辑记录表格格式错误 |
| `E401` | warn | 红链（目标页不存在） |
| `E402` | warn | 跨页锚点不存在 |
| `E501` | warn | 未知板块（已按自定义板块保留） |
| `E502` | warn | 行首未转义的 `@` |
| `E503` | info | 首个 `@` 之前的正文被当成序言 |
| `E504` | warn | 同一板块重复出现 |
| `E505` | warn | 缺少序言 |
| `E506` | warn | 两个页面标题相同 |
| `E507` | info | 缺少详细内容 |
| `E508` | warn | 自定义板块名撞了规范板块名（会被当成规范板块解析） |
| `E509` | warn | 自定义板块重名（`get_section` 只返回第一个） |
| `E601` | info | 孤岛页面 |
| `E602` | info | 自链接 |

## 6. 作者须知（真实的坑）

1. **块级公式 `$$…$$` 必须独立成段**（前面留空行），否则会被当成行内公式。
2. 正文行首若要写**字面 `@`**，请写成 `\@`；行首字面 `:::` 写成 `\:::`。
3. 代码块里的 `[[x]]` 在 `md` 模式下也会被当链接；需要字面量时写 `\[[x]]`。
4. 目录只收 `详细内容` 和自定义板块里的标题；`::: text` 围栏里的 `#` 不算标题。
5. 编辑记录**不会被其它编辑操作自动写入**，需要显式调用 `add_edit_record` / `wikiencoder log`。
6. 改完记得跑 `wikiencoder validate`。
